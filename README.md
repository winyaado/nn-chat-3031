# NNチャット
ZEN大学 Webアプリケーション開発3
https://github.com/nnn-training/nn-chat-3031 をもとに提出用に改良したアプリケーションです

## 追加機能

元リポジトリ `nn-chat-3031-main-2026` から、提出用に以下の機能を追加・改善しました。

### 板機能

- 板一覧画面を追加しました。
- 板ごとに投稿を分けて表示できるようにしました。
- 初期板「メイン」を自動作成し、既存投稿は「メイン」に紐づけます。
- 板名は空文字禁止、50文字以内、重複禁止です。
- 板削除はソフトデリートで実装しています。
- 削除済み板は一覧に表示せず、URLで直接アクセスしても `/boards` に戻します。
- 板を削除できるのは `admin` または板の作成者だけです。

### 投稿アンカー機能

- 各投稿に `#投稿ID` のアンカーリンクを追加しました。
- 本文中の `>>1` のような記法を投稿リンクに変換します。
- アンカージャンプ時に固定ヘッダーで投稿が隠れないように表示位置を調整しました。

### 検索機能

- 板一覧画面から、削除済み板を除くすべての投稿を検索できるようにしました。
- チャット画面から、現在の板の投稿だけを検索できるようにしました。
- 検索結果から該当投稿へ直接ジャンプできます。

### 起動・運用の改善

- `/posts` は初期板「メイン」のチャット画面へリダイレクトするようにしました。
- Docker Compose起動時に `npm install`、`prisma generate`、`prisma db push` を自動実行するようにしました。
- `DATABASE_URL` は `.env` から読み込む構成にしました。
- Renderなどの本番環境でHTTPアクセスを拒否する処理を追加しました。

### UI改善

- 板一覧への戻りボタンをチャット画面に追加しました。
- 板削除・投稿削除時に確認ダイアログを表示するようにしました。
- 投稿本文内のHTMLタグがエスケープされる既存の安全性を維持しています。

## 必要な環境

- Docker Desktop
- Docker Compose

Node.jsを直接使う場合は Node.js 22 以上が必要です。

## 環境変数

`.env` に `DATABASE_URL` を設定します。

```env
DATABASE_URL="postgresql://postgres:postgres@db:5432/nn_chat"
```

Docker Composeでは `env_file` 経由で `.env` を読み込みます。

## 起動方法

```sh
docker compose up
```

起動後、ブラウザで以下を開きます。

```txt
http://localhost:8000/
```

初回起動時やスキーマ変更後は、起動コマンド内で以下が自動実行されます。

```sh
npm install
npx prisma generate
npx prisma db push
node index.js
```

## テスト

```sh
npm test
```

## 画面とURL

| URL | 内容 |
| --- | --- |
| `/boards` | 板一覧 |
| `/boards/:id/posts` | 板ごとのチャット |
| `/search?q=キーワード` | すべての投稿を検索 |
| `/boards/:id/search?q=キーワード` | 指定した板の投稿を検索 |
| `/posts` | 初期板「メイン」へリダイレクト |

## 板機能

初期板として「メイン」が自動作成されます。

既存投稿で `boardId` が未設定のものは、初期板「メイン」に自動で紐づけられます。

板削除はソフトデリートです。削除済み板は一覧に表示されず、URLで直接アクセスした場合も `/boards` に戻されます。

板を削除できるのは以下のユーザーです。

- `admin`
- 板を作成したユーザー

## 投稿アンカー

各投稿には `#投稿ID` のリンクが表示されます。

本文中に以下のように書くと、投稿へのアンカーリンクに変換されます。

```txt
>>1
```

アンカージャンプ時は固定ヘッダーに隠れないよう、表示位置を調整しています。

## 検索機能

板一覧画面の検索バーでは、削除済み板を除くすべての投稿を検索します。

チャット画面の検索バーでは、現在表示している板の投稿だけを検索します。

検索対象は投稿本文です。

## セキュリティ上の注意

このアプリはBasic認証を使っています。公開環境ではHTTPSを有効にしてください。
